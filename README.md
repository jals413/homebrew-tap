# Homebrew tap for Breather

[Breather](https://github.com/jals413/breather) is a free, open-source Mac app with break reminders that live in your MacBook's notch.

```bash
brew install --cask jals413/tap/breather
```

Update with `brew upgrade --cask breather`. Uninstall with `brew uninstall --zap --cask breather`.

Breather isn't notarized by Apple (that needs a paid developer account), so this cask clears macOS's download quarantine after installing. The cask is updated automatically by Breather's release workflow.
